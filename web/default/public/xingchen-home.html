Quick Start

三步接入，零改造迁移

兼容 OpenAI 与 Anthropic 协议。已有项目只需替换 Base URL 与 API Key，即可立即切换。

  1. 1

    注册并创建令牌

    登录控制台，在「令牌」页面创建 API Key，并按需选择分组。

  2. 2

    替换 Base URL

    OpenAI 格式使用 https://ai.centos.hk/v1；Claude Code 等 Anthropic 客户端使用 https://ai.centos.hk。

  3. 3

    选择模型，开始调用

    同一个 Key 调用所有已开通的模型，统一余额扣费，用量实时可查。
